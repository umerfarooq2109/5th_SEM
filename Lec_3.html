Part 01Foundations

1. What are Operators? & 2. Types of Operators in Python

1. WHAT ARE OPERATORS?

Operators are special symbols or keywords in Python that perform operations on values or variables (called operands). An operator takes one or more operands and produces a result.

Example

5 + 3
Here, + is the operator, and 5 and 3 are the operands. The evaluated result is 8.

Python has several categories of operators, and each category behaves with specific syntax and evaluation rules.

2. TYPES OF OPERATORS IN PYTHON

Python organizes its operators into the following distinct categories:

  1. Arithmetic Operators — Mathematical computations (+, -, *, /, //, %, **).
  2. Assignment Operators — Assigning values and in-place updates (=, +=, -=, *=, :=).
  3. Comparison (Relational) Operators — Value comparisons returning Booleans (==, !=, >, <, >=, <=).
  4. Logical Operators — Boolean combining and short-circuit evaluation (and, or, not).
  5. Identity Operators — Memory address / object reference checking (is, is not).
  6. Membership Operators — Sequence and container search (in, not in).
  7. Bitwise Operators — Bit-level manipulation on integers (&, |, ^, ~, <<, >>).
  8. Operator Precedence and Associativity — The rule system deciding the execution order when multiple operators appear in a single expression (a rule system, not a separate category, but essential!).
Part 02Mathematics

3. Arithmetic Operators

Arithmetic operators are used to perform standard mathematical calculations on numeric operands.

Operator Meaning Example Result
+ Addition 7 + 3 10
- Subtraction 7 - 3 4
* Multiplication 7 * 3 21
/ Division (always returns float) 7 / 2 3.5
// Floor Division (rounds down towards -∞) 7 // 2 3
% Modulus (remainder of division) 7 % 2 1
** Exponentiation (power) 7 ** 2 49
Points Often Not Known by Beginners
  • Floor division (//) rounds down toward negative infinity, not toward zero. This causes a surprising result with negative numbers:
    Example: -7 // 2 → gives -4 (not -3, as many expect).
  • The difference between / and //: / is true division, always returning a float (e.g. 7 / 2 = 3.5). // is floor division; it divides two numbers and gives the nearest whole number by always rounding down (7 // 2 = 3, but -7 // 2 = -4, not -3).
  • ** (power) also works with negative and fractional exponents:
    Example: 4 ** 0.5 → gives 2.0 (this is how you get a square root in Python without importing any library).
    Example: 2 ** -1 → gives 0.5.

The Walrus Operator (:=)

Introduced in Python 3.8, the walrus operator (:=) is called an "assignment expression" rather than a plain statement. It allows you to assign a value to a variable and immediately use it in the same expression, most commonly inside loop conditions (while (data := file.read(1024)):) or if statements (if (n := len(items)) > 5:).

Chained Comparisons in Python

Python allows chained comparisons, which is a powerful feature not present in most C-family languages:

Example

Part 05Short-Circuiting

6. Logical Operators

Used to combine multiple Boolean expressions / conditions.

Operator Meaning Example Result
and True only if BOTH operands are True True and False False
or True if AT LEAST ONE operand is True True or False True
not Reverses the Boolean value not True False
Short-Circuit Evaluation & Operand Return Values

Python's and / or do not always return True or False — they can return one of the actual operand values, not just a Boolean. This is called short-circuit evaluation:

  • 5 and 8 → gives 8 (not True) — because both are truthy, Python returns the second value.
  • 0 and 8 → gives 0 — because 0 is falsy, Python stops and returns 0 immediately without checking the second operand.
  • 5 or 8 → gives 5 — because 5 is already truthy, Python returns it immediately without checking the second operand.
  • Real-World Code Shortcut: name = user_input or "Default" — this assigns "Default" only if user_input is falsy (like an empty string).

Part 06Memory References

7. Identity Operators

Used to check whether two variables point to the exact same object in memory — not just whether they have equal values.

Operator Meaning
is True if both variables refer to the exact same object in memory
is not True if both variables refer to different objects in memory
Point (Very Important, Commonly Confused with ==)

• == checks if the values are equal.
• is checks if they are the exact same object in memory.

Rule to remember: Always use == for comparing values. Only use is when checking singleton sentinels like None (e.g. if x is None:).

Part 08Bit Manipulation

9. Bitwise Operators

These work at the binary (bit) level of numbers — they treat numbers in their raw binary form (0s and 1s).

Operator Meaning Example Result
& Bitwise AND 5 & 3 1
| Bitwise OR 5 | 3 7
^ Bitwise XOR 5 ^ 3 6
~ Bitwise NOT (inverts bits) ~5 -6
<< Left shift 5 << 1 10
>> Right shift 5 >> 1 2
Points Often Not Known by Beginners
  • Bit-by-bit comparison: 5 in binary is 101, 3 in binary is 011. So 5 & 3 compares bit by bit: 101 & 011 = 001, which is 1 in decimal.
  • Left shift (<<) by 1 position is equivalent to multiplying by 2 (5 << 1 = 10).
  • Right shift (>>) by 1 position is equivalent to integer-dividing by 2 (5 >> 1 = 2).
  • ~ (bitwise NOT) formula: Uses the two's complement inversion formula: ~x = -(x + 1). That is why ~5 = -6!

Part 09Evaluation Rules

10. Operator Precedence and Associativity

What is Operator Precedence?

Operator precedence is the set of rules Python follows to decide which operator gets evaluated first when an expression contains more than one operator. Operators with higher precedence are evaluated before operators with lower precedence (like BODMAS / PEMDAS in mathematics).

result = 5 + 3 * 2
# * has higher precedence than +, so multiplication happens first
# 3 * 2 = 6, then 5 + 6 = 11
# result = 11, NOT (5 + 3) * 2 = 16
What is Associativity?

Associativity is the rule that decides the order of evaluation when two or more operators of the SAME precedence appear together in one expression. It tells Python whether to evaluate from Left to Right or Right to Left. 

result = 20 - 5 - 3
# both operators are - (same precedence), and - is left-to-right:
# (20 - 5) - 3 = 15 - 3 = 12
# result = 12  (NOT 20 - (5 - 3) = 18)
Why Do We Need Both Rules?

• Precedence: Decides order between DIFFERENT operators.
• Associativity: Decides order between SAME-precedence operators.

Full Operator Precedence Table (Highest to Lowest)
Level Operator(s) Description Associativity
1 (Highest) ( ) Parentheses (grouping) N/A (Always calculated completely first)
2 ** Exponentiation (power) Right to Left
3 +x, -x, ~x Unary plus, unary minus, bitwise NOT Right to Left
4 *, /, //, % Multiplication, Division, Floor Division, Modulus Left to Right
5 +, - Addition, Subtraction (binary) Left to Right
6 <<, >> Bitwise left shift, right shift Left to Right
7 & Bitwise AND Left to Right
8 ^ Bitwise XOR Left to Right
9 | Bitwise OR Left to Right
10 ==, !=, >, <, >=, <=, is, is not, in, not in Comparison, Identity, Membership Left to Right
11 not Logical NOT Right to Left
12 and Logical AND Left to Right
13 or Logical OR Left to Right
14 (Lowest) := Walrus / Assignment expression Right to Left
Examples of Precedence from Notes
  • Example A — Multiplication before Addition: 10 + 2 * 3 → 2 * 3 = 6, then 10 + 6 = 16.
  • Example B — Exponent before Multiplication: 2 * 3 ** 2 → 3 ** 2 = 9, then 2 * 9 = 18.
  • Example C — Comparison happens after Arithmetic: 5 + 3 > 2 * 3 → 8 > 6 → True.
  • Example D — 'and' has higher precedence than 'or': True or False and False → (False and False) is False, then True or False → True (Beginners wrongly assume left-to-right reading here!).
Examples of Associativity from Notes
  • Example A — Exponent is Right to Left (most important trap): 2 ** 3 ** 2 → 2 ** (3 ** 2) = 2 ** 9 = 512 (WRONG left-to-right assumption gives 64).
  • Example B — Subtraction is Left to Right: 50 - 10 - 5 → (50 - 10) - 5 = 35.
  • Example C — Division is Left to Right: 100 / 5 / 2 → (100 / 5) / 2 = 20.0 / 2 = 10.0.
  • Example D — Unary Minus is Right to Left: -2 ** 2 → -(2 ** 2) = -4 (Unary minus has lower precedence than exponentiation).
  • Example E — Walrus (:=) is Right to Left: if (n := 5 + 3) > 5: print(n) → n = 8, then 8 > 5 → True.
Using Parentheses to Override Precedence

2 + 3 * 2 gives 8, while (2 + 3) * 2 forces addition first and gives 10. Parentheses make code unambiguous and self-documenting.

Step-by-Step Solved Questions from Notes
Question 1: Evaluate result = 2 + 3 * 4 ** 2 // 5

• Step 1: Highest precedence is ** (exponent). Compute 4 ** 2 = 16.
• Step 2: Expression becomes: 2 + 3 * 16 // 5.
• Step 3: * and // share precedence (left-to-right): 3 * 16 = 48.
• Step 4: Expression becomes: 2 + 48 // 5.
• Step 5: Floor division: 48 // 5 = 9.
• Step 6: Addition: 2 + 9 = 11.
Final Answer: 11

Question 2: Chained Comparison — Evaluate result = 10 > 5 == True

• Step 1: This is a chained comparison: (10 > 5) and (5 == True).
• Step 2: 10 > 5 → True.
• Step 3: 5 == True → 5 == 1 → False.
• Step 4: True and False → False.
Final Answer: False

print("Step 1 (10 > 5)       =", step1)
step2 = 5 == True
print("Step 2 (5 == True)     =", step2)
step3 = step1 and step2
print("Step 3 (True and False)=", step3)
print("Final result           =", result)
Output

Step 1 (10 > 5)       = True
Step 2 (5 == True)     = False
Step 3 (True and False)= False
Final result           = False
Question 3: Mixing Comparison, Arithmetic & Logical — result = 5 + 3 > 2 and 10 // 3 == 3

• Step 1: Arithmetic first → 5 + 3 = 8 and 10 // 3 = 3.
• Step 2: Expression becomes: 8 > 2 and 3 == 3.
• Step 3: Comparisons next → 8 > 2 → True and 3 == 3 → True.
• Step 4: Logical and → True and True → True.
Final Answer: True

11. Augmented Assignment Operators

What is Augmented Assignment?

An augmented assignment operator is a shorthand way of combining an arithmetic or bitwise operation with assignment in a single step (x += 5 instead of x = x + 5).

Why Use Augmented Assignment?
  • Makes code shorter and cleaner, especially inside loops.
  • Prevents typing mistakes by not repeating long variable names twice.

Part 11Type Transformation

12. Type Conversion (Implicit & Explicit)

A. Implicit Type Conversion (Automatic)

Happens automatically without writing conversion code. Python does this safely when combining a smaller/less precise type with a larger/more precise type (e.g. int + float → float). Python never silently converts a string to a number (e.g. "5" + 2 raises a TypeError).

a = 5        # int
b = 2.5      # float
c = a + b    # Python converts 'a' to float before adding
print(c, type(c)) # 7.5 <class 'float'>
B. Explicit Type Conversion (Manual / Type Casting)
Function Converts To Example Result
int() Integer (truncates towards zero) int("42"), int(3.9), int(-3.9) 42, 3, -3
float() Float float("3.14"), float(7) 3.14, 7.0
str() String str(100), str(3.14) "100", "3.14"
bool() Boolean bool(0), bool(1), bool(""), bool("a") False, True, False, True
list() List list("abc") ['a', 'b', 'c']
tuple() Tuple tuple([1, 2, 3]) (1, 2, 3)
set() Set (Removes duplicates) set([1, 1, 2, 3]) {1, 2, 3}
4 Important Points from Notes
  • 1. int() cannot directly convert a decimal string: int("25.5") raises ValueError. Correct way: int(float("25.5")) → 25.
  • 2. Converting True/False to int: int(True) = 1, int(False) = 0 (because bool subclasses int).
  • 3. Whitespace rules: int("25 ") = 25 (trailing/leading space allowed), but int("2 5") raises ValueError (internal spaces forbidden).
  • 4. Unconvertible strings: int("hello") raises ValueError: invalid literal for int() with base 10: 'hello'.
Part 12Precision

13. Rounding in Python

Basic Usage of round()
  • Rounding to nearest whole number: round(7) = 7, round(3.14159) = 3.
  • Rounding to decimal places: round(3.14159, 2) = 3.14. Note: round(x, 0) returns a float (3.0), while round(x) returns an int (3).
  • Rounding to tens, hundreds (negative second argument): round(12345, -2) = 12300, round(12345, -3) = 12000.
"Banker's Rounding" (Round Half to Even)

Python's round() does NOT always round 0.5 upward. Instead, when a number is exactly halfway between two possibilities, Python rounds to whichever neighboring whole number is even:

Expression Result Explanation
round(0.5) 0 Rounds down because 0 is even
round(1.5) 2 Rounds up because 2 is even
round(2.5) 2 Rounds down because 2 is even
round(3.5) 4 Rounds up because 4 is even
Floating-Point Binary Precision Quirk

round(2.675, 2) gives 2.67 instead of 2.68 because 2.675 cannot be stored exactly in binary floating-point (internally it is stored as 2.6749999999999998...).

round() vs int() — Not the Same Thing
Expression Result Behavior
int(3.9) 3 Truncates — simply cuts off the decimal part
round(3.9) 4 Rounds to the nearest whole number
int(3.1) 3 Truncates — cuts off the decimal part
round(3.1) 3 Rounds to the nearest whole number

14. Cryptographic Security & The secrets Module

The standard random module is predictable and unsuitable for security. The Python standard library provides the secrets module for generating cryptographically strong random numbers suitable for managing data such as passwords, account authentication, security tokens, and related secrets.

secrets_security_demo.py 
# Example: Secure random numbers
import secrets 
 
# Secure random integer 
print("Secure randbelow(100):", secrets.randbelow(100))        # Random int from 0 to 99 
 
# Secure random token (for passwords, API keys) 
print("Token Hex (16 bytes)   :", secrets.token_hex(16))         # 32-character hex string 
print("Token URL-Safe (16)    :", secrets.token_urlsafe(16))     # URL-safe base64 string 
 
# Secure random choice password generator
password_chars = "abcdefghijklmnopqrstuvwxyz0123456789!@#$%" 
password = ''.join(secrets.choice(password_chars) for _ in range(12)) 
print(f"Generated password     : {password}")

Lecture 3 Summary & Key Takeaways

This lecture covered the full breadth of Python operators, execution order, type casting, rounding mathematics, and security:

  • The 8 Core Categories: Arithmetic, Assignment, Relational, Logical, Identity (is vs ==), Membership (in), Bitwise, and Precedence / Associativity.
  • Floor Division Mechanics: // rounds toward negative infinity (-7 // 2 = -4).
  • Logical Short-Circuiting: and and or return the operand value that settled the evaluation (5 and 8 = 8, 10 or 0 = 10).
  • Identity vs Equality: == checks value equality; is checks whether both references share the same memory address (id(a) == id(b)).
  • Precedence Traps: ** is right-to-left (2 ** 3 ** 2 = 512). Unary minus has lower precedence than exponent (-2 ** 2 = -4). Chained comparison 10 > 5 == True evaluates as (10 > 5) and (5 == True) → False.
  • Type Casting & Rounding: int() truncates decimals. round() uses Banker's Rounding (half to even) to eliminate statistical bias.
  • Cryptographic Security: Always use secrets (never random) for generating tokens, passwords, and security keys.
