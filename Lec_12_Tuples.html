📘 Section 01 • Fundamentals

1. Introduction to Tuples

1.1 What is a Tuple?

Definition: A tuple is an ordered collection of items in Python. Once a tuple is created, its items cannot be changed (added, removed, or replaced). This property is called immutable.

Think of a tuple like a sealed box of items. You can look at the items inside, count them, and copy them, but you cannot change what is inside the box.

A tuple is written with round brackets () and the items are separated by commas.

Python Code • Basic Tuple
fruits = ("apple", "banana", "cherry")
print(fruits)
🖥️ Output (Rendered ASCII Output)
('apple', 'banana', 'cherry')

1.2 Main Features of a Tuple

  • Ordered — items stay in the same order in which you wrote them.
  • Immutable — you cannot change, add, or delete items after creation.
  • Allows duplicates — the same value can come many times, like (1, 2, 2, 3).
  • Can store different data types — numbers, text, boolean, even other tuples or lists together.
  • Indexed — every item has a position number. The first item has index 0.
  • Faster than a list — because Python knows it will never change.

2.1 Index Numbers (Positive and Negative)

Every item in a tuple has two index numbers: a positive one counted from the left and a negative one counted from the right.

Item"A""B""C""D""E"

Negative index-5-4-3-2-1
Remember: The first item is at index 0, not 1. The last item is always at index -1.

📌 Program 3: count() and index() Methods

📘 Section 05 • Gotchas

5. Important Points

Point 1: A single-item tuple needs a comma

Python Code • Single-Item Tuple
a = (5)     # this is just an integer
b = (5,)    # this is a tuple
print(type(a))
print(type(b))
🖥️ Output (Rendered ASCII Output)

Point 2: A tuple can hold a list, and that list CAN change

The tuple itself is fixed, but if one of its items is a list, the list inside can still be changed.

Python Code • Tuple with Mutable Item
t = (1, [2, 3], 4)
t[1].append(99)   # changing the list inside the tuple
print(t)
🖥️ Output (Rendered ASCII Output)
(1, [2, 3, 99], 4)

Point 4: A function can return many values, and Python returns them as a tuple

Python Code • Multiple Return Values
def min_max(numbers):
    return min(numbers), max(numbers)

result = min_max([4, 9, 1, 7])
print(result)
print(type(result))
🖥️ Output (Rendered ASCII Output)
(1, 9)

Point 5: Tuples are compared item by item

Python Code • Tuple Comparison
print((1, 2, 3) < (1, 2, 4))
print((5, 1) > (4, 100))
print((1, 2) == (1, 2))

📘 Section 06 • Comparison

6. Difference Between Tuple and List

Both tuples and lists store many items in one variable, and both are ordered and allow duplicates. The big difference is that a list can be changed and a tuple cannot.

Easy way to remember:
List = a notebook written with a pencil (you can erase and write again).
Tuple = a book printed with ink (you can read it, but you cannot change it).
PointTupleList
BracketsRound brackets ( )Square brackets [ ]
Changeable?No, it is immutableYes, it is mutable
Add / remove itemsNot possiblePossible with append(), remove(), pop()
Methods availableOnly 2: count(), index()Many: append, insert, sort, reverse, etc.
SpeedFasterSlightly slower
Memory usedLessMore
SafetyData is protected from accidental changeData can be changed by mistake

6.2 Memory Check

Python Code • Memory Check
import sys

t = (1, 2, 3, 4, 5)
l = [1, 2, 3, 4, 5]

print("Tuple uses less memory than list:", sys.getsizeof(t) < sys.getsizeof(l))
🖥️ Output (Rendered ASCII Output)

6.3 When Should I Use Which?

Simple Rule:
Use a tuple when the data should never change (birth date, GPS location, days of the week).
Use a list when the data will grow, shrink, or change (to-do list, student names, scores).

📌 Program 5: Indexing and Slicing

Definition: Indexing means getting one item using its position number. Slicing means getting a part of the tuple using [start:stop:step]. The stop position is not included.

📌 Program 9: Student Report using Tuples (Practical Program)

Definition: This real-life program stores student names and their marks in nested tuples. It uses unpacking, sum(), len(), a formatted print, and max() with a key to find the topper.

Python Code • Program 9
students = (
    ("Asha",  (85, 90, 78)),
    ("Bilal", (92, 88, 95)),
    ("Chen",  (70, 65, 80)),
)

print("Name    Total   Average")
print("-" * 24)

for name, marks in students:
    total = sum(marks)
    avg = total / len(marks)
    print(f"{name:<7} {total:<7} {avg:.2f}")

topper = students[0]
highest_marks = sum(topper[1])

for s in students:
    total = sum(s[1])
    if total > highest_marks:
        highest_marks = total
        topper = s

print("Topper of the class:", topper[0])
