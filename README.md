## ✨ Portal Key Features
- **Integrated Single-Page Reader**: Study all 14 modules seamlessly without page redirects.
- **Embedded Python 3.12 WebAssembly Playground**: Run Python code directly in the browser with full IntelliSense and terminal execution.
- **Real-Time Search & Category Filters**: Search across 320+ programs and theoretical concepts.
- **Study Progress Tracker**: Save and resume your syllabus completion progress in `localStorage`.
- **Dark / Light Mode**: Seamless theme synchronization across the portal and nested lecture notes.
