📘 Section 01 • Creation

1. Dictionary Creation

A dictionary in Python is an unordered collection of key-value pairs. It is mutable, meaning you can change, add, or remove items after creation. Keys must be unique and immutable (like strings, numbers, or tuples).

1.1 Using Curly Brackets

Python Code
student = {"name": "Asha", "age": 20, "course": "CSE"}

1.2 Empty Dictionary

Python Code
empty = {}

1.3 Using dict() with Keyword Arguments

Python Code
car = dict(brand="Toyota", model="Innova", year=2022)
📌 Program 1: Basic Dictionary Creation
Python Code • Program 1
student = {"name": "Asha", "age": 20, "course": "CSE"}
empty = {}
car = dict(brand="Toyota", model="Innova", year=2022)

print(student)
print(empty)
print(car)
print(type(student))
🖥️ Output (Rendered ASCII Output)
{'name': 'Asha', 'age': 20, 'course': 'CSE'}
{}
{'brand': 'Toyota', 'model': 'Innova', 'year': 2022}

📌 Program 2: Dictionary Comprehension

Create a dictionary using a loop-like syntax in a single line.

1.5 From Two Lists or a List of Tuples

📌 Program 3: Creating from Lists/Tuples

zip() combines two sequences element-by-element.

Python Code • Program 3
keys = ["a", "b", "c"]
values = [1, 2, 3]

# zip() is used to combine two or more sequences element-by-element.
d1 = dict(zip(keys, values))       # from two lists

pairs = [("x", 10), ("y", 20)]
d2 = dict(pairs)                   # from list of tuples

print(d1)
print(d2)
🖥️ Output (Rendered ASCII Output)
{'a': 1, 'b': 2, 'c': 3}
{'x': 10, 'y': 20}

1.6 Using fromkeys()

📌 Program 4: Using fromkeys()

Create a dictionary where all keys share the same initial value.

Python Code • Program 4
subjects = ["Maths", "Physics", "Chemistry"]
marks = dict.fromkeys(subjects, 0)
print(marks)

no_value = dict.fromkeys(["a", "b"])
print(no_value)
🖥️ Output (Rendered ASCII Output)
{'Maths': 0, 'Physics': 0, 'Chemistry': 0}
{'a': None, 'b': None}

📌 Master Operations Program: All 22 Operations

A single, comprehensive program that demonstrates every operation in order.

Python Code • Master Program
d = {'name': 'Umer', 'age': 21, 'city': 'Delhi'}
print('--- DICTIONARY OPERATIONS ---\n')

# 1. Access value
print('1. Access value: d["name"] =>', d['name'])

# 2. get()
print('2. get(): d.get("age") =>', d.get('age'))
print('   d.get("phone", "Not Found") =>', d.get('phone', 'Not Found'))

# 3. Add item
d['email'] = 'umer@gmail.com'
print('3. Add item: d["email"] = "umer@gmail.com" =>', d)

# 4. Modify item
d['age'] = 22
print('4. Modify item: d["age"] = 22 =>', d)

# 5. update()
d.update({'phone': '9876543210', 'city': 'Mumbai'})
print('5. update(): d.update({"phone": "9876543210", "city": "Mumbai"}) =>', d)

# 6. pop()
removed = d.pop('email')
print('6. pop(): d.pop("email") =>', removed, '| dict now:', d)

# 7. popitem()
last = d.popitem()
print('7. popitem(): d.popitem() =>', last, '| dict now:', d)

# 8. del
del d['city']
print('8. del: del d["city"] => dict now:', d)

# 9. clear()
d2 = {'a': 1, 'b': 2}
d2.clear()
print('9. clear(): d2.clear() =>', d2)

# 10. keys()
print('10. keys(): d.keys() =>', list(d.keys()))

# 11. values()
print('11. values(): d.values() =>', list(d.values()))

# 12. items()
print('12. items(): d.items() =>', list(d.items()))

# 13. Looping
print('13. Looping: for k in d:')
for k in d:
    print('    ', k, '=>', d[k])

# 14. Membership
print('14. Membership: "name" in d =>', 'name' in d)
print('    "email" in d =>', 'email' in d)

# 15. len()
print('15. len(): len(d) =>', len(d))

# 16. copy()
d3 = d.copy()
print('16. copy(): d.copy() =>', d3)

# 17. setdefault()
val = d.setdefault('country', 'India')
print('17. setdefault(): d.setdefault("country", "India") =>', val, '| dict now:', d)

# 18. Merging
d4 = {'x': 10, 'y': 20}
d5 = {'y': 99, 'z': 30}
merged = d4 | d5
print('18. Merging: {"x":10,"y":20} | {"y":99,"z":30} =>', merged)

# 20. Sorting
marks = {'Math': 90, 'English': 75, 'Science': 88, 'Hindi': 60}
print('20. Sorting: sorted(marks.items()) =>', sorted(marks.items()))

# 21. min / max / sum
print('21. min/max/sum on marks.values():', list(marks.values()))
print('    min =>', min(marks.values()), '| max =>', max(marks.values()), '| sum =>', sum(marks.values()))

📌 Operation 13: Looping Through a Dictionary
Python Code
marks = {"Maths": 90, "Physics": 85, "Chemistry": 78}

print("--- Keys ---")
for key in marks:
    print(key)

print("--- Values ---")
for value in marks.values():
    print(value)

print("--- Key and Value ---")
for subject, score in marks.items():
    print(subject, "->", score)

📌 Operation 21: min(), max() and sum() on a Dictionary
Python Code
marks = {"Maths": 90, "Physics": 85, "Chemistry": 78}

print("Total   :", sum(marks.values()))
print("Highest :", max(marks.values()))
print("Lowest  :", min(marks.values()))
print("Average :", round(sum(marks.values()) / len(marks), 2))
print("Best subject :", max(marks, key=marks.get))
print("Weak subject :", min(marks, key=marks.get))
🖥️ Output (Rendered ASCII Output)

Lowest  : 78
Average : 84.33
Best subject : Maths
