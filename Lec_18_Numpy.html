1. Introduction to NumPy

1.1 What is NumPy?

DEFINITION: NumPy stands for Numerical Python. It is a free and open-source Python library used for fast mathematical work, especially on large collections of numbers.

NumPy (short for Numerical Python) is the most important library in Python for working with numbers, arrays, and mathematical operations. It was created by Travis Oliphant in 2005 and is completely free and open-source.

It was built on top of the NumPy library and is the foundation for libraries like Pandas, Scikit-learn, TensorFlow, and Matplotlib.

1.2 Why do we need NumPy?

  • Python lists are flexible but slow for number crunching.
  • NumPy gives us a special container called the ndarray (N-dimensional array) that is fast and uses less memory.
  • Almost every data science library (Pandas, SciPy, scikit-learn, TensorFlow, Matplotlib) is built on top of NumPy.
  • Fast array operations — written in C behind the scenes.
  • Supports multi-dimensional arrays (1D, 2D, 3D, ... nD).
  • Broadcasting — perform operations on arrays of different shapes.
  • Built-in mathematical functions (sin, cos, mean, sum, etc.).
  • Memory efficient — stores data in a contiguous block of memory.

1.3 Installing and Importing

2. What is a NumPy Array?

A NumPy array (also called ndarray) is a grid of values where all values are of the same type. The items are stored one after another in memory, which is why NumPy is fast.

ndarray stands for N-dimensional array. 'N-dimensional' means the array can have any number of dimensions.

  • 0-D array (scalar): a single value, e.g. np.array(5)
  • 1-D array (vector): a list of values, e.g. [1, 2, 3]
  • 2-D array (matrix): rows and columns, e.g. [[1, 2], [3, 4]]
  • 3-D array (tensor): many matrices stacked together

3. Arrays vs Lists

3.1 Theory

A Python list is a general-purpose container. It can hold anything: numbers, text, other lists, even a mix. It stores references (pointers) to separate objects scattered in memory.

A NumPy array stores raw values of one type side by side in one continuous block of memory. Because the type is known, NumPy can use fast, pre-compiled C code to work on all values at once.

Why are arrays faster?

  1. Same type — Python does not need to check each item's type during every operation.
  2. Continuous memory — the CPU reads the data quickly.
  3. Vectorization — one operation is applied to the whole array without writing a Python for loop.
  4. Compiled C code — the heavy work is done in C, not in slow Python.

4. Data Types in NumPy

4.1 Theory

Every NumPy array has one data type for all its elements, stored in the dtype attribute. The data type tells NumPy:

  • what kind of data it is (integer, decimal, True/False, text ...)
  • how many bits/bytes each element uses

Choosing the right dtype saves memory and controls the precision of your numbers.

4.8 Upcasting (Automatic Type Promotion)

When you mix types in one operation, NumPy picks the type that can hold both without losing information.

Python Code

result = i + f
print(result)        # [1.5 2.5 3.5]
print(result.dtype)  # float64

print(np.array([1, 2.5, True]).dtype) # float64

4.9 Overflow: A Danger of Small Data Types

If a number is outside the range of its dtype, it "wraps around" like a car odometer. NumPy does not always warn you.

📌 Program: Overflow
Python Code
import numpy as np

a = np.array([200], dtype=np.uint8) # uint8 max is 255
print(a + 100) # [44] (300 - 256 = 44)

b = np.array([120], dtype=np.int8) # int8 max is 127
print(b + 10) # [-126] (wrapped around!)
🖥️ Output (Rendered ASCII Output)
[44]
[-126]
⚠️ Lesson: Smaller dtypes save memory but can give wrong answers if your values are large. Choose carefully.

6. Indexing & Slicing

6.1 Theory

Once you have an array, you will want to pick out some of its values. NumPy gives you several ways to do this:

  • Indexing means getting one element using its position (index).
  • Slicing means getting a range of elements, like "the first three" or "every second one".
  • Fancy indexing means picking elements using a list of positions.
  • Boolean indexing means picking elements using a True / False condition.
💡 Key Idea: NumPy indexing starts at 0, not 1. The first element is at index 0, the second at index 1, and so on. Negative indexes count from the end: -1 is the last element.

8. Broadcasting

8.1 Theory

Normally, to add two arrays they must have the same shape. Broadcasting is NumPy's clever trick that lets it work with arrays of different shapes, by automatically "stretching" the smaller array so that it matches the bigger one.

Think of it like this: you want to add 10 to every number in a table. You do not have to build a whole table full of 10s. You just write table + 10 and NumPy understands.

💡 Key Idea: The stretching is virtual. NumPy does not really make copies of the small array in memory. It just repeats the values while calculating. That makes broadcasting both fast and memory friendly.

Why do we need it?

  • It removes the need for slow Python loops.
  • It makes code short and easy to read.
  • It saves memory, because no big temporary arrays are created.
  • It is used everywhere: scaling data, subtracting the mean, adding a bias, making tables, and much more.

The simplest broadcasting is between an array and a single number (scalar). The scalar is stretched to every position.

8.4 The Broadcasting Rules

NumPy compares the shapes of the two arrays from the last (rightmost) dimension to the first. Two dimensions are compatible when:

  1. Rule 1: If the arrays have different numbers of dimensions, the shape of the smaller one is padded with 1s on the left.
  2. Rule 2: Dimensions are compatible if they are equal, or if one of them is 1. A dimension of size 1 is stretched to match the other.
  3. Rule 3: If any pair is neither equal nor 1, NumPy raises a ValueError.

The shape of the result is the larger size in each dimension.

(3, 1)(1, 4)(3, 1) and (1, 4)Yes(3, 4)

9. Binary Operators

9.1 Theory

A binary operator is a symbol that works on two values (operands), like + in a + b. In NumPy, binary operators work on whole arrays at once, element by element. That means the first element of a is combined with the first element of b, the second with the second, and so on.

Behind every operator there is a NumPy function called a ufunc (universal function). For example, a + b secretly calls np.add(a, b). Both give the same answer.

💡 Key Idea: If the two arrays have different shapes, broadcasting is applied first. If the shapes cannot be matched, you get a ValueError.

10. Mathematical Functions

10.1 Theory: Universal Functions (ufuncs)

NumPy comes with hundreds of mathematical functions. Most of them are universal functions, or ufuncs. A ufunc takes an array and applies the same calculation to every element, at C speed, with no Python loop.

Element-wise ufuncs return an array of the same shape: np.sqrt, np.sin, np.exp, np.round. Aggregate functions reduce many values to fewer: np.sum, np.mean, np.max, np.std. Cumulative functions keep a running result: np.cumsum, np.cumprod.

💡 Key Idea: Python's math module works on one number at a time. NumPy functions work on a whole array at once. math.sqrt([1, 4, 9]) fails, but np.sqrt([1, 4, 9]) works.
