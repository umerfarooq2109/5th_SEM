1. The if Statement (One-Way Decision)

1.1 What is an if Statement?

An if statement lets your program make a decision. It checks a condition, and if that condition evaluates to True, it runs a designated block of code. If the condition is False, that block is simply skipped — the program moves on to whatever statement comes after it.

Think of it like a real-life instruction: "If it is raining, take an umbrella." If it is NOT raining, you simply don't take the umbrella — there is no alternative instruction given. This is exactly what makes if a one-way decision.

🛣️ One-Way Decision Flow

The program follows a single guarded branch. If the test condition passes, code executes; otherwise, execution flows past the block without any action.

⚖️ Truthy & Falsy Evaluation

Python evaluates any expression after if. Non-zero numbers, non-empty strings, and non-empty collections evaluate to True; 0, None, and "" evaluate to False.

1.2 General Syntax

Notice two syntactic fundamentals carefully: the line ends with a colon (:), and the code that belongs to the if block is indented (standard 4 spaces). Python uses indentation to define block scope.

General syntax of a single-alternative selection structure in Python:

if_syntax.py
if condition:
    # block of statements executed only when condition is True
    statement_1
    statement_2

1.3 Foundational Example & Execution Mechanics

In this foundational example, Python checks whether age >= 18. Since age = 20, the boolean condition evaluates to True, executing the indented print() statement.

If age had been 15, the condition would be False, skipping the print line entirely.

voting_check.py
age = 20

if age >= 18:
    print("You are eligible to vote.")

print("Program continues to the next statement.")
▶ Terminal Output
You are eligible to vote.
Program continues to the next statement.
⚠️ Important Point: Indentation is Not Optional

In languages like C, C++, or Java, indentation is purely for human readability — curly braces { } define scope. In Python, there are no curly braces for block scoping: indentation itself is the grammar. Incorrect indentation raises an IndentationError or causes subtle logical bugs.

1.4 Key Points Often Missed by Beginners

  • Flexible Condition Expressions: The condition does not need to be a simple variable comparison. It can be any logical expression, function call, or compound statement joined with and, or, not.
  • Multi-line Blocks: An if block can contain as many lines as needed, provided all lines share the exact same indentation level.
  • Silent Continuation: When an if condition is False without an else branch, execution silently continues to the next statement without error.
  • Mandatory Colon: Forgetting the colon (:) after the condition causes an immediate SyntaxError.

2. Two-Way if-else Statement

2.1 What is a Two-Way if-else Statement?

A plain if statement only tells Python what to do when the condition is True — it has nothing to say about the False case. The if-else statement fixes this by providing two distinct pathways: one to follow when the condition evaluates to True, and a completely separate alternative when it is False.

Real-Life Analogy: "If it is raining, take an umbrella; otherwise, wear sunglasses." Now there is an explicit, proactive instruction for both possibilities.

The term "two-way" refers to the fact that there are exactly two mutually exclusive branches:

  • The if branch: Executes if and only if the test condition evaluates to True.
  • The else branch: Executes if and only if the test condition evaluates to False.
  • Mutual Exclusion Guarantee: Exactly one of these two blocks will run — never both, and never neither.

2.2 General Syntax & Execution Model

Syntax of a two-alternative selection structure in Python:

if_else_syntax.py
if condition:
    # block of statements executed when condition is True
    statement_1
    statement_2
else:
    # block of statements executed when condition is False
    statement_3
    statement_4

2.3 Important Rules & Points to Remember

🚫 else Never Takes a Condition

Writing else condition: is a fatal SyntaxError. The else keyword is a blanket catch-all that automatically handles everything that made the if condition False.

📏 Colons & Vertical Alignment

Both if and else must end with a colon (:) and must start at the exact same indentation column.

3. Nested if Statements (Decisions within Decisions)

3.1 What is a Nested if Statement?

A nested if statement occurs when an entire if, if-else, or if-elif-else block is placed inside the body of another if or else statement.

Real-Life Analogy: Think of an airport security checkpoint:

  1. Outer Check: Do you have a valid boarding pass? If False, you cannot enter the airport.
  2. Inner Check: Did you pass baggage screening? If True, you proceed to the boarding gate; if False, security intervention is required.

The inner question is only ever asked if you successfully cleared the outer checkpoint. If the outer condition fails, the entire inner decision tree is skipped completely.

3.2 General Syntax & Indentation Architecture

In Python, block nesting is defined purely by indentation levels:

Structural hierarchy of a 2-tier nested conditional block:

nested_if_syntax.py
if outer_condition:
    # Runs only when outer_condition is True
    statement_outer_1

    if inner_condition:
        # Runs only when BOTH outer_condition AND inner_condition are True
        statement_inner_1
    else:
        # Runs when outer_condition is True BUT inner_condition is False
        statement_inner_2

else:
    # Runs when outer_condition itself is False
    # (The inner if is never even checked)
    statement_outer_2

3.3 Critical Rules of Nested Execution

🔑 Prerequisite Dependency

The inner conditional block is completely shielded by the outer condition. It is executed if and only if the outer block evaluates to True.

📐 Multi-Level Indentation

Outer statements use 4 spaces (Level 1); inner statements use 8 spaces (Level 2); deeper nesting uses 12 spaces (Level 3).

4. The if – elif – else Statement (Multi-Way Decision)

4.1 What is a Multi-Way if-elif-else Statement?

When you need your program to choose among more than two mutually exclusive possibilities, a simple if-else is insufficient. Python provides the elif keyword (short for "else if") to build a multi-way decision ladder.

Top-Down Evaluation Semantics: Python evaluates the conditions sequentially from top to bottom. As soon as it encounters the first condition that evaluates to True, it executes that block of code and immediately skips the rest of the entire chain. If none of the conditions match, the optional fallback else block executes.

4.2 General Syntax

Structural syntax of Python's multi-alternative decision chain:

if_elif_else_syntax.py
if condition_1:
    # Runs if condition_1 is True
    statement_1
elif condition_2:
    # Runs if condition_1 was False and condition_2 is True
    statement_2
elif condition_3:
    # Runs if condition_1 and 2 were False, and condition_3 is True
    statement_3
else:
    # Runs if NONE of the above conditions were True
    statement_fallback

4.3 Keyword Comparison: if vs elif vs else

Keyword Technical Purpose Allowed Frequency Requires Condition Expression?
if Initiates the conditional chain; evaluates the first test. Exactly one (Mandatory start) Yes (Mandatory boolean expression)
elif Tests supplementary conditions only if all preceding tests failed. Zero or more (Arbitrary count) Yes (Mandatory boolean expression)
else Default fallback block; executes when all prior conditions were False. Zero or one (Optional, must be last) No (Never takes an expression)

4.6 Master Capstone Project: Automated ATM Console Banking Simulation

An integrated real-world application from the lecture notes showcasing PIN authentication loops, nested input validations, menu dispatching via if-elif-else, overdraft protection, and transaction logging.

atm_banking_system.py
# =========================================================
# ATM CONSOLE BANKING SIMULATION SYSTEM
# Features: PIN Authentication, Balance Inquiry, Deposit,
#           Withdrawal with Overdraft Protection, Mini Statement
# =========================================================

pin = "1234"
balance = 10000.00
transactions = ["Initial Balance: $10000.00"]
attempts = 0
max_attempts = 3
is_logged_in = False

# 1. PIN Verification Loop (Simulated 1 valid attempt)
entered_pin = "1234"
if entered_pin == pin:
    is_logged_in = True
    print("PIN Accepted. Authentication Successful!\n")
else:
    attempts += 1
    print(f"Invalid PIN. Remaining attempts: {max_attempts - attempts}")

if is_logged_in:
    print("=" * 45)
    print("       WELCOME TO SSM DIGITAL BANK ATM")
    print("=" * 45)
    print("1. Check Account Balance")
    print("2. Deposit Funds")
    print("3. Withdraw Cash")
    print("4. View Mini Statement")
    print("5. Exit Session")
    print("=" * 45)

    # Simulated Actions Demonstration
    # Action A: Deposit $2500
    deposit_amount = 2500.00
    if deposit_amount <= 0:
        print("Error: Deposit amount must be positive.")
    else:
        balance += deposit_amount
        transactions.append(f"Deposited: +${deposit_amount:.2f}")
        print(f"Successfully deposited ${deposit_amount:.2f}. Updated Balance: ${balance:.2f}")

    # Action B: Withdraw $4000
    withdraw_amount = 4000.00
    if withdraw_amount <= 0:
        print("Error: Withdrawal amount must be positive.")
    elif withdraw_amount > balance:
        print(f"Declined: Insufficient funds! Current Balance: ${balance:.2f}")
    else:
        balance -= withdraw_amount
        transactions.append(f"Withdrawn: -${withdraw_amount:.2f}")
        print(f"Successfully withdrawn ${withdraw_amount:.2f}. Updated Balance: ${balance:.2f}\n")

    # Action C: Print Mini Statement
    print("--- MINI STATEMENT (Last Transactions) ---")
    for tx in transactions:
        print(f"  • {tx}")
    print(f"Available Balance: ${balance:.2f}")
    print("Thank you for banking with SSM Digital Bank!")
