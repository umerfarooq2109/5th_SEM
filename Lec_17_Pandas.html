📘 Section 01 • Fundamentals

1. Introduction to Pandas

1.1 What is Pandas?

DEFINITION: Pandas is a free and open-source Python library used for data handling, data cleaning, and data analysis. It gives us easy-to-use data structures (Series and DataFrame) to store and work with data in the form of tables.

The name "Pandas" comes from Panel Data, a term used in statistics for data with many rows and columns. It was created by Wes McKinney in 2008 and is built on top of the NumPy library.

Think of Pandas as Microsoft Excel inside Python. In Excel you open a sheet, sort it, filter it, find the average, and fix empty cells. Pandas lets you do all these things by writing small pieces of code, and it can handle millions of rows very quickly.

1.2 Why do we use Pandas?

  • Easy to use: a table of data can be created in one line of code.
  • Fast: it is built on NumPy, so calculations on big data are quick.
  • Handles missing data: it has ready-made methods to find, fill, or remove empty values.
  • Reads and writes many file types: CSV, Excel, JSON, SQL, HTML, and more.
  • Powerful operations: sorting, filtering, grouping, merging, joining, and reshaping data.
  • Labelled data: every row and column has a name (label), so data is easy to find.
  • Works with other libraries: NumPy, Matplotlib, Seaborn, and Scikit-learn.

1.3 Installation and Importing

Pandas is not part of basic Python. It must be installed once using pip:

pip install pandas

After installation, we import it in every program. By tradition, everybody uses the short name (alias) pd.

2. Series

2.1 What is a Series?

DEFINITION: A Series is a one-dimensional, labelled array in Pandas that can store data of any type (numbers, text, True/False, etc.). It has two parts: the values (the data) and the index (the labels of the data).

A Pandas Series is a one-dimensional labeled array capable of holding data of any type. It can be created from Python lists, NumPy arrays, dictionaries, scalar values, or data loaded from external sources such as CSV files, Excel files, and databases. The labels associated with a Series are called its index.

The word one-dimensional means that the data is arranged in a single sequence, like a list. Each element in a Series has two parts:

  • Index: The label used to identify an element. By default, Pandas assigns indexes starting from 0.
  • Value: The actual data stored at that index.

For example, consider the following Series:

IndexValue
0U
1M
2E
3R
4F

Here, U has index 0, M has index 1, and so on.

Imagine one column of an Excel sheet. On the left you see the row numbers (the index) and next to them the data (the values). That is exactly a Series.

2.2 Creating a Series

pd.Series(data, index=None, dtype=None, name=None)
  • data: the values — can be a list, dictionary, NumPy array, or a single (scalar) value.
  • index: the labels for the values. If we do not give it, Pandas uses 0, 1, 2, ...
  • dtype: the data type of the values (int, float, object, etc.).
  • name: a name for the Series.

3. DataFrame

3.1 What is a DataFrame?

DEFINITION: A DataFrame is a two-dimensional, labelled data structure in Pandas that stores data in rows and columns, just like a table in a database or a sheet in Excel. Each column can hold a different type of data.

A DataFrame can be seen as a collection of Series that share the same index. Every column is a Series.

IndexNameAgeCity

1Anita22Mumbai
2Kiran20Chennai

In this table: the left-most numbers (0, 1, 2) are the index (row labels); Name, Age, City are the columns (column labels); and the cells hold the values.

📘 Section 04 • Data Cleaning

4. Missing Data

4.1 What is Missing Data?

DEFINITION: Missing data means that some cells of a table are empty or have no value. In Pandas, a missing value is shown as NaN (Not a Number). For missing dates it is shown as NaT (Not a Time), and Python's own None is also treated as missing.

Real-world data is rarely perfect. A person may not fill a form field, a sensor may stop working, or a file may get damaged. If we ignore the empty cells, calculations like average can become wrong, and many machine-learning programs even stop with an error. So handling missing data is an important step of data cleaning.

5.2 Measures of Central Tendency

  • Mean (average): Sum of all values divided by the number of values.
  • Median (middle value): The middle value when data is arranged in order. If the number of values is even, it is the average of the two middle values. The median is not affected by very large or very small values (outliers).
  • Mode (most frequent value): The value that appears most often. A data set can have more than one mode, so mode() returns a Series.

5.4 Measures of Shape: Skewness and Kurtosis

  • Skewness (skew()): Tells whether the data is balanced (symmetric) or leaning to one side. Skew = 0 means symmetric. Positive skew means a long tail on the right (a few very high values). Negative skew means a long tail on the left (a few very low values).
  • Kurtosis (kurt()): Tells how sharp (peaked) or flat the data is and how heavy its tails are. Pandas gives "excess kurtosis" (a normal distribution has kurtosis 0).
Formula for Skewness:
Skewness = [n / ((n-1)(n-2))] * Σ((x_i - x̄) / s)^3
Where n is the number of observations, x̄ is the mean, and s is the standard deviation.

5.6 Variance - A Detailed Calculation

DEFINITION: Variance is a statistical measure that tells us how much the data values are spread out from their average (mean).

In simple words:

  • Low variance: Data values are close to the mean.
  • High variance: Data values are far away from the mean.
  • Zero variance: All data values are exactly the same.

StepCalculationResult
1. Find Mean(10 + 20 + 30 + 40 + 50) / 530
2. Difference from Meanx - Mean-20, -10, 0, 10, 20
3. Square the differences(x - Mean)^2400, 100, 0, 100, 400
4. Sum of squares400 + 100 + 0 + 100 + 4001000
5. Apply Variance formulaVariance = 1000 / (5 - 1) = 1000 / 4250
6. Standard DeviationSD = √25015.81

Common Mistakes to Avoid

  • Writing pd.DataFrame() or pd.Series() — the correct names are pd.DataFrame() and pd.Series() (capital D, F, and S).
  • Using and / or for conditions — use & / | with brackets.
  • Writing print(df.info()) — it prints None at the end. Write only df.info().
  • Forgetting to store the result: df.dropna() does not change df. Write df = df.dropna().
  • Using unequal list lengths in a dictionary when creating a DataFrame — it gives a ValueError.
  • Forgetting index=False in to_csv(), which adds an extra "Unnamed: 0" column when the file is read again.
  • Writing attributes with brackets (df.shape()) or methods without brackets (df.head). Attributes: shape, columns, dtypes. Methods: head(), info(), describe().
  • Confusing loc (labels, end included) and iloc (positions, end excluded).
