Defining a Function in Python

💡
Core Definition: A function definition in Python is a named, reusable block of statements encapsulated using the def keyword, which binds a callable function object to an identifier in the current namespace.

def Statement def func_name(params): Keyword header initiating function creation and header signature definition.
Function Name Identifier Snake_case naming Legal Python identifier bound to the created function object in memory.
Parameter List (p1, p2, ...) Comma-separated list of formal placeholder variables inside parentheses.
Function Header Colon : at end of def line Required syntax punctuation demarcating the transition to the indented suite.
Indented Function Body 4-space indentation The block of statements executed sequentially whenever the function is invoked.
Docstring '''docstring''' Optional triple-quoted string immediately following the header providing documentation.
pass Statement def stub(): pass Null placeholder statement allowing syntactically valid empty function stubs.
Function Object Binding type(f) is function Creating a function instantiates a first-class function object on the heap.
Type Annotations def f(x: int) -> str: Optional type hints documenting expected input and output data types.
Function Attribute Dunder func.__name__, func.__doc__ Built-in metadata attributes attached to every Python function object.

Nested Function Definition (Helper Function)

Defines a parent function containing an internal helper function to compute statistical z-scores.

program_009.py 
# Defining a nested helper function inside a parent function
def compute_z_score(data_point, dataset):
    # Internal helper function to compute mean
    def calculate_mean(values):
        return sum(values) / len(values)

    # Internal helper function to compute standard deviation
    def calculate_std(values, mean_val):
        variance = sum((x - mean_val) ** 2 for x in values) / len(values)
        return variance ** 0.5

    mean = calculate_mean(dataset)
    std_dev = calculate_std(dataset, mean)
    z = (data_point - mean) / std_dev
    return round(z, 4)

scores = [65, 75, 80, 85, 90, 95]
x_val = 90
print(f"Dataset: {scores}")
print(f"Z-Score for {x_val}: {compute_z_score(x_val, scores)}")

Function Invocations & Call Mechanics

💡
Core Definition: A function call is the runtime execution mechanism triggered by appending parentheses () to a callable object, which allocates a new stack frame, transfers control flow, binds arguments, and returns upon completion.
Concept / Mechanism Syntax Archetype Academic Definition & Execution Rule
Call Operator () func() Parentheses operator instructing Python to transfer execution to the function's bytecode.
Actual Arguments func(val1, val2) Concrete values, expressions, or variable references passed into the function call.
Control Flow Transfer Caller -> Callee -> Caller Execution suspends at call site, executes function body, and resumes after return.
Call Stack Activation Stack Frame Allocation Memory block allocated on the runtime call stack storing local variables and return address.
Expression Evaluation func(2 + 3, x * 4) Expressions passed as arguments are fully evaluated before entering the function body.
Chained Function Calls f(g(h(x))) Nesting calls where return values of inner functions serve as inputs to outer functions.
Method Invocation obj.method() Calling a function bound to an object instance with implicit self parameter passing.
Callable Object Check callable(obj) Built-in function testing whether an object supports the invocation operator ().
Call Stack Frames sys._getframe() Activation record tracking caller scope and active execution depth in memory.
Higher-Order Invocations map(func, iterable) Passing a function reference into another function to be invoked dynamically.

Return Values & Output Mechanics

💡
Core Definition: The return statement terminates function execution immediately and passes a specified result object back to the caller; if omitted or executed without an expression, Python implicitly returns None.
Concept / Mechanism Syntax Archetype Academic Definition & Execution Rule
return Statement return expression Halts function execution and yields the evaluated expression back to the call site.
Implicit None Return return with no expr Functions without a return statement automatically evaluate and return None.
Early Exit (Guard Clauses) if invalid: return Returning early upon detecting invalid inputs or boundary conditions to prevent deep nesting.
Void Functions (Procedures) def proc(): print() Functions executed solely for side-effects that return None.
Value-Returning (Fruitful) def calc(): return x Functions that compute and return a meaningful value or data structure.
Single vs Multiple Exits Multiple return stmts Having multiple return statements inside conditional branches to handle discrete outcomes.
Returning Complex Objects return dict / list / obj Returning complex composite data structures, dictionaries, or custom class instances.
Returning Callables (Closures) return inner_function Returning a function object from another function for factory generators.
Unreachable Dead Code code after return Statements placed immediately after a return statement in the same block are never executed.
Return Value Binding result = func() Assigning the returned object to a variable or passing it directly into an expression.

💡
Core Definition: Python uses 'Pass-by-Object-Reference' (Call-by-Sharing), where object references are passed by value: in-place mutations on mutable objects affect the caller, but reassigning parameter identifiers binds locally without altering caller references.
Concept / Mechanism Syntax Archetype Academic Definition & Execution Rule
Pass-by-Object-Reference Call-by-Sharing Python's evaluation strategy passing references (pointers) to heap objects by value.
Immutable Types int, float, str, tuple Objects whose state cannot be modified in-place; modifications create new objects.
Mutable Types list, dict, set Objects supporting in-place modifications (e.g. append, pop) visible across aliases.
In-Place Mutation lst.append(x) Modifying the underlying heap object without changing the variable reference pointer.
Reassignment Rebiding param = new_value Rebinding a parameter identifier to a new object, disconnecting it from caller.
Object Identity (id()) id(obj) Unique integer memory address of an object verifying whether variables reference same object.
Shallow Copying lst.copy(), lst[:] Creating a new outer container while retaining references to inner elements.
Deep Copying copy.deepcopy(obj) Recursively cloning a container and all its nested sub-objects in memory.
Augmented Assignment Mutability += operator behavior List += mutates in-place (extend), while integer/string += rebinds locally.
Defensive Copying Pattern def f(lst): lst = lst.copy() Copying mutable inputs at function entry to guarantee caller data immutability.

# Trampoline Pattern: Simulating TCO in Python
def trampoline(generator_func):
    """Executes tail-call thunks iteratively to eliminate stack frames."""
    def wrapper(*args, **kwargs):
        g = generator_func(*args, **kwargs)
        while callable(g):
            g = g()
        return g
    return wrapper

    if n <= 1:
        return acc
    # Return a zero-argument callable thunk instead of direct recursion
    return lambda: factorial_thunk(n - 1, n * acc)

@trampoline
def factorial_trampolined(n, acc=1):
    return factorial_thunk(n, acc)
