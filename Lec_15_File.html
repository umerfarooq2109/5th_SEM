📘 Section 01 • Fundamentals

1. Introduction to File Handling

1.1 What is a File?

Definition: A file is a named place on the hard disk where data is stored permanently. File handling means creating, reading, writing, and closing files from a Python program.

Think of a notebook. When you write something in it, the writing stays there even after you close the notebook. A variable is like writing on a whiteboard: when the program ends, everything is erased. A file is the notebook; it keeps your data safe for the next time.

1.2 Why Do We Need File Handling?

  • Permanent storage — variables are stored in RAM and are lost when the program ends. Files stay on the disk.
  • Large data — a file can store a lot more data than we can type again and again.
  • Sharing data — one program can write a file and another program can read it.
  • Backup and records — marks, bills, logs, and settings are all saved in files.

1.8 Closing a File

close() ends the connection between the program and the file. It saves the data that was waiting in memory (the buffer) and frees computer resources.

  • If you forget to close a file opened for writing, some data may not be saved.
  • Too many open files can slow down the program or cause errors.
  • After close(), we cannot read or write that file. Python raises a ValueError.

1.9 The with Statement (Best Way)

Definition: The with statement opens a file and closes it automatically when the block ends, even if an error comes in the middle. No need to call close().
with open("hello.txt", "r") as f:
    data = f.read()

2.3 Write Mode ("w")

In write mode, we open a file only for writing. If the file does not exist, Python creates it. If it already exists, all its old content is erased and writing starts from the beginning.

  • Syntax: open("file.txt", "w")
  • We cannot read from this file.
  • write() writes one string.
  • writelines() writes a list of strings.
  • write() does not add a new line. We must add \n ourselves.

2.6 Exclusive Creation Mode ("x")

In exclusive mode, Python creates a new file and opens it for writing. If the file already exists, it raises FileExistsError. It protects us from erasing a file by mistake.

📌 Program: Creating a New File Safely
Python Code
with open("report.txt", "x") as f:
    f.write("Annual report\n")
print("File created.")

try:
    with open("report.txt", "x") as f:
        f.write("Another report\n")
except FileExistsError:
    print("File already exists. Not overwritten.")

with open("report.txt") as f:
    print(f.read())

2.7 Read and Write Mode ("r+")

r+ opens an existing file for both reading and writing. The pointer starts at the beginning, and the old content is not erased. New text overwrites the old text at the pointer position. A missing file gives FileNotFoundError.

📌 Program: Read and Overwrite
Python Code
with open("rplus.txt", "w") as f:
    f.write("Hello World")

with open("rplus.txt", "r+") as f:
    print("Read :", f.read(5))
    f.seek(0)
    f.write("Jolly")
    f.seek(0)
    print("Updated:", f.read())

Updated: Jolly World

2.10 Binary Modes ("rb", "wb", "ab" and more)

In binary mode, the file is handled as bytes, not as text. We add the letter b to the mode. Reading gives a bytes object (like b"Hello") and writing needs bytes too. Binary modes are used for images, audio, video, and pickle files.

📌 Program: Write Binary
Python Code

nums = bytes([65, 66, 67])

with open("data.bin", "wb") as f:
    f.write(data)
    f.write(nums)

with open("data.bin", "rb") as f:

3. Pickling

3.1 What is Pickling?

Definition: Pickling is the process of converting a Python object (list, dictionary, class object, etc.) into a stream of bytes so that it can be saved in a file. Unpickling is the reverse: reading those bytes and building the original object again. The module used is pickle.

Think of pickling food: you preserve a vegetable in a jar so that it stays safe for a long time, and later you take it out and use it. In the same way, pickling preserves your object in a file, and unpickling brings it back. Another name for this is serialization (pickling) and deserialization (unpickling).

  • Pickle files are binary files, so we always use "wb" and "rb" modes.
  • It saves the whole object with its data type. A list comes back as a list, not as text.
  • The file is not readable in Notepad.
  • Usual extension: .pkl or .pickle.
  • It works only with Python. Other languages cannot read it easily.

3.2 Why Do We Use Pickling?

  • Save the program state — a game score, a list of students, a trained model.
  • Store complex data easily — no need to convert each item into text.
  • Send objects between programs or over a network.

3.3 Functions of the pickle Module

pickle.dumps(obj)Pickles obj and returns bytes (no file)
pickle.loads(bytes)Builds the object back from bytes

4.1 Errors in Python

While writing programs, three kinds of mistakes can happen.

4.2 What is an Exception?

Definition: An exception is an error that happens while the program is running and stops the normal flow. Exception handling means catching the error and giving a proper reply, so the program does not crash.

Imagine you are going to college and the bus does not come. A good plan: if the bus does not come, take an auto. That plan is exception handling. Without a plan, you are just stuck.

4.5 Multiple except Blocks

One try can have many except blocks. Python checks them from top to bottom and runs the first one that matches.

📌 Program: Multiple except Blocks
Python Code
def divide(a, b):
    try:
        return a / b
    except ZeroDivisionError:
        return "Cannot divide by zero"
    except TypeError:
        return "Please use numbers only"

print(divide(10, 2))
print(divide(10, 0))
print(divide(10, "a"))

4.7 Getting the Error Message (as e)

Write as e after the exception name to store the exception object in e. Printing e shows the error message. Exception catches almost every error.

📌 Program: Capturing Error Messages
Python Code
try:
    x = int("hello")
except ValueError as e:
    print("Message:", e)

try:
    numbers = [1, 2, 3]
    print(numbers[10])
except Exception as e:
    print("Type :", type(e).__name__)
    print("Message:", e)
🖥️ Output (Rendered ASCII Output)

Remember: A bare except: (without a name) catches everything, even a Ctrl+C. It hides mistakes, so avoid it. Catch the specific exception you expect.
