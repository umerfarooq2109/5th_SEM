📘 Section 01 • Fundamentals

1. Introduction to Files in Python

1.1 What is a File?

A file is a named location on your computer's storage (hard disk or SSD) that stores data permanently. When your program ends, the data in variables is lost — but data saved in files stays forever until you delete it.

In simple words: A file is like a notebook where you write information and keep it safe. You can open it later, read it, add more information, or erase things. Python gives us built-in functions to work with files — no extra library needed!

1.2 Types of Files

TypeExtension ExamplesContentHow Python Reads It
Text Files.txt, .csv, .html, .py, .jsonHuman-readable charactersLine by line as strings
Binary Files.jpg, .png, .mp3, .exe, .pkl, .pdfRaw bytes (0s and 1s)As bytes objects

Text files store data as characters (letters, numbers, symbols). You can open them in Notepad and read them.

Binary files store data in raw binary format. If you open an image in Notepad, you will see garbage characters — that's because it's binary data.

1.3 File Operations Overview

When working with files, you always follow these steps:

  1. Open the file
  2. Read / Write / Append
  3. Close the file
⚠️ Warning: Always close a file after you are done with it! If you forget, data may not be saved properly and your file could get corrupted.

1.4 Opening and Closing Files

📐 Syntax:
open(filename, mode) — Opens a file and returns a file object.
file_object.close() — Closes the file and frees system resources.
📌 Program: Opening and Closing Files
Python Code
# Opening and closing a file
f = open("example.txt", "r")   # Open for reading
content = f.read()                   # Read all content
print(content)
f.close()                            # Always close the file!

# Better way: using 'with' (auto-closes the file)
with open("example.txt", "r") as f:
    content = f.read()
    print(content)
# File is automatically closed here — no need to call close()
💡 Tip: The 'with' statement is the recommended way to work with files in Python. It automatically closes the file for you, even if an error occurs!

📘 Section 03 • Serialization

3. Pickling (Serialization)

3.1 What is Pickling?

Pickling is the process of converting a Python object (like a list, dictionary, or class) into a byte stream so that it can be saved to a file or sent over a network. This process is also called serialization.

Unpickling is the reverse — converting the byte stream back into a Python object. This is called deserialization.

TermProcessDirectionFunction
Pickle (Serialize)Object → Bytes → FileSavingpickle.dump()
Unpickle (Deserialize)File → Bytes → ObjectLoadingpickle.load()
Think of it like this:
Pickling = Packing your clothes into a suitcase (object → file)
Unpickling = Unpacking the suitcase and getting your clothes back (file → object)
📝 Note: Python's pickle module is used for pickling. Always import it first: import pickle

3.2 How to Pickle (Serialize) — Saving Objects to Files

📐 Syntax:
pickle.dump(object, file) — Saves the object to the file.
pickle.dumps(object) — Returns the pickled bytes (without saving to file).
📌 Program: Pickling (Saving) Objects
Python Code
import pickle

# ─── Example 1: Pickle a list ───
fruits = ["Apple", "Banana", "Cherry", "Date", "Elderberry"]

# Save the list to a binary file
with open("fruits.pkl", "wb") as f:  # 'wb' = write binary
    pickle.dump(fruits, f)
print("List has been pickled (saved) to fruits.pkl!")

# ─── Example 2: Pickle a dictionary ───
student = {
    "name": "Rahul Sharma",
    "age": 20,
    "marks": [85, 92, 78, 95, 88],
    "passed": True
}

with open("student.pkl", "wb") as f:
    pickle.dump(student, f)
print("Dictionary has been pickled to student.pkl!")
🖥️ Output (Rendered ASCII Output)
List has been pickled (saved) to fruits.pkl!
Dictionary has been pickled to student.pkl!
❗ Important: Always open pickle files in binary mode ('wb' for writing, 'rb' for reading). Pickle data is NOT human-readable — it's raw bytes!

3.3 How to Unpickle (Deserialize) — Loading Objects from Files

📐 Syntax:
pickle.load(file) — Reads and returns the object from the file.
pickle.loads(bytes) — Converts pickled bytes back to an object.

import pickle

    loaded_fruits = pickle.load(f)

print("Type:", type(loaded_fruits))

# ─── Load the dictionary back ───

print("Loaded student:", loaded_student)
print("Name:", loaded_student["name"])
print("Marks:", loaded_student["marks"])

4.4 Multiple except Blocks

Python Code • Multiple except
# Handling multiple exception types
def divide(a, b):
    try:
        result = a / b
        print(f"{a} / {b} = {result}")
    except ZeroDivisionError:
        print("Error: Cannot divide by zero!")
    except TypeError:
        print("Error: Please use numbers only!")
    except Exception as e:
        print(f"Unexpected error: {e}")

# Test with different inputs
divide(10, 2)   # Normal case
divide(10, 0)   # ZeroDivisionError
divide("10", 2) # TypeError (in some operations)
divide(10, "abc") # TypeError

Error: Cannot divide by zero!
10 / 2 = 5.0
Error: Please use numbers only!
❗ Important: Always put specific exceptions before general ones. Python checks from top to bottom and uses the first matching except block. If you put 'except Exception' first, it will catch everything and your specific handlers will never run!

4.6 try-except-finally

📐 Syntax:
try:
    # Code that might fail
except ExceptionType:
    # Runs if error occurred
finally:
    # ALWAYS runs — error or no error!

The finally block ALWAYS executes, no matter what — even if an exception occurs, even if you use return inside try. It is perfect for cleanup operations like closing files or database connections.

Python Code • finally
# finally ALWAYS runs
print("--- Case 1: No Error ---")
try:
    result = 10 / 2
    print(f"Result: {result}")
except ZeroDivisionError:
    print("Cannot divide by zero!")
finally:
    print("Finally block executed!")

print()

print("--- Case 2: With Error ---")
try:
    result = 10 / 0
    print(f"Result: {result}")  # Never runs
except ZeroDivisionError:
    print("Cannot divide by zero!")
finally:
    print("Finally block executed!")  # Still runs!

Finally block executed!

4.8 Custom Exceptions (User-Defined Exceptions)

You can create your own exception types by making a class that inherits from the Exception class:

Python Code • Custom Exceptions
# Creating custom exceptions
class InvalidMarkError(Exception):
    """Raised when marks are not in valid range (0-100)"""
    def __init__(self, marks, message="Marks must be between 0 and 100"):
        self.marks = marks
        self.message = message
        super().__init__(self.message)

    def __str__(self):
        return f"{self.message}. Got: {self.marks}"

class NegativeAgeError(Exception):
    """Raised when age is negative"""
    pass

# Using custom exceptions
def add_marks(subject, marks):
    if marks < 0 or marks > 100:
        raise InvalidMarkError(marks)
    print(f"{subject}: {marks} marks")

def set_student_age(age):
    if age < 0:
        raise NegativeAgeError(f"Age cannot be negative! Got: {age}")
    print(f"Age: {age}")

# Test
try:
    add_marks("Math", 95)      # OK
    add_marks("Science", 150)  # Error!
except InvalidMarkError as e:
    print(f"Custom Error: {e}")

try:
    set_student_age(-5)
except NegativeAgeError as e:
    print(f"Custom Error: {e}")
🖥️ Output (Rendered ASCII Output)
Math: 95 marks
Custom Error: Marks must be between 0 and 100. Got: 150
Custom Error: Age cannot be negative! Got: -5

4.9 File Handling with Exception Handling (Combining Both!)

Python Code • Safe File Reading
# Safe file reading with proper exception handling
def read_file_safely(filename):
    try:
        with open(filename, "r") as f:
            content = f.read()
            return content
    except FileNotFoundError:
        print(f"Error: File '{filename}' not found!")
        return None
    except PermissionError:
        print(f"Error: No permission to read '{filename}'!")
        return None
    except IOError as e:
        print(f"Error reading file: {e}")
        return None

# Test
content = read_file_safely("students.txt")
if content:
    print("File content loaded successfully!")
    print(content)

content = read_file_safely("nonexistent.txt")
if content is None:
    print("Could not load the file.")

import pickle
import os

FILENAME = "contacts.pkl"

def load_contacts():
    if os.path.exists(FILENAME):
        with open(FILENAME, "rb") as f:
            return pickle.load(f)
    return {}

def save_contacts(contacts):
    with open(FILENAME, "wb") as f:
        pickle.dump(contacts, f)

def add_contact(contacts):
    name = input("Enter name: ")
    phone = input("Enter phone: ")
    email = input("Enter email: ")
    contacts[name] = {"phone": phone, "email": email}
    save_contacts(contacts)
    print(f"Contact '{name}' saved!")

    if not contacts:
        print("No contacts found!")
        return
    print(f"{'Name':<15} {'Phone':<15} {'Email':<25}")
    print("-" * 55)
    for name, info in contacts.items():

def calculator():
    print("=" * 35)
    print(" ROBUST CALCULATOR")
    print("=" * 35)

    while True:
        try:
            expr = input("\nEnter expression (or 'quit'): ")
            if expr.lower() == 'quit':
                print("Goodbye!")
                break
            # Try to evaluate the expression
            result = eval(expr)
            print(f" Result: {result}")
        except ZeroDivisionError:
            print(" Error: Cannot divide by zero!")
        except SyntaxError:
            print(" Error: Invalid expression! Check your syntax.")
        except NameError as e:
            print(f" Error: Unknown variable — {e}")
        except TypeError as e:
            print(f" Error: Type mismatch — {e}")
        except Exception as e:
            print(f" Unexpected error: {type(e).__name__}: {e}")
        finally:
            print(" (Calculator is still running...)")

calculator()
